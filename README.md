# RAHUL K. — Portfolio

> BETWEEN LOGIC & CHAOS.

A personal portfolio website showcasing my work, technical expertise, experience, and projects through a cinematic and unconventional digital experience.

## About

This portfolio represents my journey as an AI & ML Engineer and Software Developer. It brings together my technical interests, projects, experience, and creative approach to building software.

Rather than following a conventional portfolio layout, the website explores a more immersive visual presentation while keeping the content accessible and intuitive.

## Tech Stack

| Technology | Purpose |
|---|---|
| Next.js | React framework |
| React | Component-based UI |
| TypeScript | Type safety |
| Tailwind CSS | Styling |
| CSS | Custom styling and animations |
| JavaScript | Interactive functionality |

## Features

- **Cinematic Landing Page** – An unconventional introduction and visual experience.
- **About Section** – Personal introduction and background.
- **Experience** – Professional and internship experience.
- **Expertise** – Technical skills and areas of interest.
- **Projects Showcase** – Selected projects and development work.
- **Contact Section** – Ways to connect and collaborate.
- **Smooth Scrolling** – Improved navigation experience.
- **Responsive Design** – Adaptable layouts across different screen sizes.
- **Motion Awareness** – Support for reduced-motion preferences.

## Getting Started

Follow these instructions to run the project locally.

### Prerequisites

- Node.js (LTS recommended)
- npm
- Git

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/Rahul-K-07/Portfolio.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Portfolio
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open your browser and visit:

   ```text
   http://localhost:3000
   ```
